## 📖 Descripción

**TENDŌ KŌRE** es una aplicación móvil de gestión comercial desarrollada con **React Native** y **Expo SDK 51**, diseñada específicamente para bodegas, tiendas de barrio y pequeños negocios. Cubre todo el ciclo de operación diaria: ventas, inventario, fiados, reportes y comunicación con clientes.

Funciona **99% sin internet** gracias a su arquitectura **SQLite local**, y se integra con **WhatsApp Business** para automatizar cobros y promociones. Sin mensualidades, sin suscripciones — un solo pago y la app es tuya para siempre.

---

## ✨ Características Principales

### 🛒 Gestión de Ventas
- **Registro Rápido:** Venta completada en segundos con búsqueda inteligente de productos
- **Formas de Pago:** Efectivo, Yape/Plin y transferencia bancaria
- **Descuentos Flexibles:** Porcentual o monto fijo por venta
- **Historial Completo:** Tracking detallado de cada transacción

### 📦 Control de Inventario
- **Stock en Tiempo Real:** Se actualiza automáticamente con cada venta
- **Alertas Inteligentes:** Notificaciones cuando el stock está por agotarse
- **Costo Promedio Ponderado:** Cálculo automático al registrar compras
- **Categorías Personalizables:** Organiza tus productos como quieras
- **Historial de Precios:** Registra cada cambio de precio en el tiempo

### 📒 Sistema de Fiados
- **Registro de Deudores:** Control detallado de clientes con crédito
- **Historial de Abonos:** Seguimiento de pagos parciales y saldos pendientes
- **Fechas y Vencimientos:** Control de plazos y alertas de deudas vencidas
- **Estados Claros:** Pendiente / Pagado / Vencido de un vistazo

### 📊 Reportes y Análisis
- **Reporte de Caja Diario:** Ventas del día por método de pago
- **Comparativas Semanales y Mensuales:** Evolución de tus ventas en el tiempo
- **Exportación HTML:** Reportes profesionales listos para compartir
- **Productos Más Vendidos:** Identifica tus best-sellers fácilmente
- **Ganancia Neta:** Cálculo automático de márgenes de utilidad

### 📱 WhatsApp Business *(Plan Premium)*
- **Mensajes de Cobro Automáticos:** Notificaciones personalizadas a deudores con un toque
- **Difusión de Promociones:** Envío masivo a clientes seleccionados
- **Recordatorios Programados:** Alertas automáticas de pago
- **Templates Editables:** Mensajes prediseñados que puedes personalizar

### 💾 Copias de Seguridad *(Plan Premium)*
- **Backup en la Nube:** Respaldo automático con Supabase
- **Restauración Simple:** Recupera todo al cambiar de celular
- **Exportar / Importar:** Portabilidad completa de tu información

## 🛠️ Stack Tecnológico

| Categoría | Tecnología |
|---|---|
| **Framework** | React Native 0.74 |
| **Runtime** | Expo SDK 51 |
| **Base de datos local** | SQLite (expo-sqlite) |
| **Backend / Nube** | Supabase (PostgreSQL) |
| **Autenticación** | Códigos de activación únicos |
| **Almacenamiento** | AsyncStorage para preferencias |
| **Navegación** | React Navigation 6 |
| **Estado global** | React Hooks + Context API |
| **Integraciones** | WhatsApp Business API, Expo Sharing |
| **UI / UX** | React Native Paper + componentes propios |
