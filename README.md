## 📖 Descripción

**TENDŌ KŌRE** es una aplicación móvil completa desarrollada con **React Native** y **Expo** diseñada específicamente para bodegas, tiendas de barrio y pequeños comercios. Funciona **99% sin internet** gracias a su arquitectura SQLite optimizada, permitiendo gestionar inventario, ventas y fiados de manera fluida incluso en zonas con conectividad limitada.

La aplicación ofrece un sistema integral que abarca desde el registro de ventas hasta reportes detallados exportables, con integración directa a **WhatsApp Business** para comunicación automatizada con clientes.

---

## ✨ Características Principales

### 🛒 Gestión de Ventas
* **Registro Rápido:** Venta en segundos con búsqueda de productos inteligente
* **Formas de Pago:** Efectivo, Yape/Plin, transferencia bancaria
* **Descuentos:** Aplicación de descuentos porcentuales o montos fijos
* **Historial Completo:** Tracking de todas las transacciones con detalles

### 📦 Control de Inventario
* **Stock en Tiempo Real:** Actualización automática con cada venta
* **Alertas Inteligentes:** Notificaciones cuando productos están por agotarse
* **Costo Promedio Ponderado:** Cálculo automático al registrar compras
* **Categorización:** Organización de productos por categorías personalizables
* **Historial de Precios:** Tracking de cambios de precio a lo largo del tiempo

### 📒 Sistema de Fiados (Cuentas por Cobrar)
* **Registro de Deudores:** Control detallado de clientes con crédito
* **Historial de Abonos:** Seguimiento de pagos parciales y saldos
* **Fechas y Vencimientos:** Control de plazos y deudas vencidas
* **Estados:** Visualización clara de deudas pendientes, pagadas o vencidas
* **Notificaciones:** Recordatorios automáticos de cobro

### 📊 Reportes y Análisis
* **Reporte de Caja Diario:** Cuánto vendiste hoy, en efectivo, digital y transferencias
* **Comparativas:** Análisis semanal y mensual de ventas
* **Exportación HTML:** Reportes profesionales listos para compartir
* **Productos Más Vendidos:** Identificación de tus best-sellers
* **Ganancia Neta:** Cálculo automático de márgenes de utilidad

### 📱 WhatsApp Business (Premium)
* **Envío Automático:** Mensajes de cobro personalizados con un toque
* **Promociones Masivas:** Difusión de ofertas a clientes seleccionados
* **Notificaciones Programadas:** Recordatorios automáticos de pago
* **Templates Personalizables:** Mensajes prediseñados editables

### 💾 Copias de Seguridad (Premium)
* **Backup Automático:** Respaldo de datos en la nube (Supabase)
* **Restauración Simple:** Recupera todo al cambiar de celular
* **Sincronización:** Mantén tus datos seguros y accesibles
* **Exportar/Importar:** Portabilidad completa de tu información

### 🔒 Operación Offline
* **99% Sin Internet:** Ventas, inventario, fiados funcionan completamente offline
* **Sincronización Inteligente:** Los datos se sincronizan cuando hay conexión
* **SQLite Local:** Base de datos rápida y confiable en el dispositivo
* **Solo Conexión Para:** Activación inicial, compartir reportes y backups

## 🛠️ Stack Tecnológico

| Categoría | Tecnología |
| :--- | :--- |
| **Framework** | React Native 0.74 |
| **Runtime** | Expo SDK 51 |
| **Base de Datos Local** | SQLite (expo-sqlite) |
| **Backend** | Supabase (PostgreSQL) |
| **Autenticación** | Códigos de activación únicos |
| **Storage** | AsyncStorage para preferencias |
| **Navegación** | React Navigation 6 |
| **Estado** | React Hooks (useState, useEffect, useContext) |
| **Integraciones** | WhatsApp Business API, Expo Sharing |
| **UI/UX** | React Native Paper, Custom Components |
